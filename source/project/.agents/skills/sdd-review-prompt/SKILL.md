# 提示词审查与行为验证

## 启动与授权

Main 在用户明确发起时选择本入口：精简过长、重复或职责混杂的指令；定位 Agent 漏执行、误判或越界；核对指令调整后的职责、授权、交接和完成判据；或比较候选改版的关键决策、结果与副作用。其他阶段完成或文件变化本身不触发审查。

入口涵盖 Skill、角色指令、AGENTS.md、共享指令和业务运行时提示词。启动时明确对象、版本、要解决的问题、场景、终点及写入边界，沿用已明确的请求。默认只审查，返回发现、证据和建议；明确授权优化或修复时才修改指令并复验。项目文档、版本、工单和有效运行证据可来自任何合格来源；业务提示词遵循已确认的业务定义。

表达、结构、去重、按需加载、场景设计和评测方法由 Agent 自主决定。权威依据冲突，或需要改变职责、授权、跨阶段推进、业务行为、整体架构或完成标准时，带依据和用户可观察的变化交 Main，由用户决定。新增外部权限、费用或真实环境写入须确认相应授权，优先使用已获授权的隔离环境。只暂停受影响项及其依赖。

## 审查、修订与复验

1. **建立基线。** 用已确认依据定预期，分开记录原版偏差及证据缺口。沿实际入口核对权威来源、加载条件、优先级、作用域及决策时的可达性。只补读影响本轮判断的内容。
2. **提取可追溯规则。** 记录来源、条件、负责方、动作或禁止项、授权、例外与完成判据。用任务 DAG 表达关键场景的可观察读取、决策、操作、交接及取证，标明分支、必要依赖、禁止路径和完成证据；重试按次展开。
3. **归并发现。** 给出位置、受影响规则或节点、触发场景、后果、影响和修订建议。区分相同作用域和优先级下的重复、无关读取、冲突、歧义及可按需加载的材料；检查目标、职责、触发、授权、例外、交接与完成判据。
4. **按授权修订。** 重组、精简、消歧或调整加载方式，保留独有条件、例外与约束，把前后版本映射到同一规则，确认适用路径仍能及时取得规则。原版有偏差时以已确认预期为准。
5. **按场景复验。** 覆盖正常路径、易混分支、授权边界、适用例外、失败恢复和完成判据。比较前后版本时使用相同输入、权限、工具、模型配置和等价初始状态。记录实际读取、决策、动作或拒绝、产物和副作用；要判断稳定性时同配置复跑关键场景并记录差异。失败按证据继续授权内修订并复验。Token 与读取量为辅助数据。

其他 Skill 只作为源码或验证对象读取。需运行被测指令时，明确隔离评测的场景、权限和外部写入边界，用获授权的环境或替身取证。被测 Skill 的受控执行仅用于评测。禁止在本工作流调用其他 Skill、将其执行作为前置条件或自动推进其他阶段。

## 阶段内执行安排

本 Skill 按[最小交接](../../sdd/references/delegation.md#最小交接)显式选择具备能力的执行者，每次给出目标、授权、写入边界、输入和完成条件，再核对实际回执。角色名称是可替换的能力映射，技能执行者可直接承接相应工作。

| 所需能力 | 安排与回执 |
| --- | --- |
| 核心语义审查、指令修订 | 技能执行者或具备提示词审查能力的执行者，返回规则表、任务 DAG、发现及获授权的修订和依据 |
| 评测工具和自动化夹具 | 通常由 sdd-coder 承接，返回工具改动、运行入口、自验证据和能力限制 |
| 隔离运行环境 | 通常由 sdd-devops 承接，返回环境、模型与工具配置、运行标识及故障证据 |
| 核对业务提示词的预期 | 按需安排 sdd-product-manager，从已确认需求提取用户可观察判据，返回判据、来源和歧义 |
| 独立复验 | 技能执行者或具备能力的独立执行者，按既定场景核对关键动作、结果、副作用和缺口 |

角色直接使用项目依据、适用共享规则和模板完成本职任务，禁止加载工作流 Skill 或互相委派。跨职责事项先返回本 Skill，跨阶段再交 Main。`sdd-doc-consistency` 的只读职责排除运行时提示词和指令，不承担核心提示词审查。

## 交付

回执汇总范围、规则表和任务 DAG、发现与证据；修订轮另给出实际改动、逐场景结果、稳定性证据（适用时）及未验证范围。项目写入限于授权对象：取证用工具输出，回执直接在回复交付；只有报告或证据落盘也获授权时才写入项目，按需沿用已有记录或使用[提示词审查回执](../../sdd/assets/prompt_review_template.md)。静态对照和运行行为验证分开报告，运行证据不足时标明缺项、影响和恢复条件。

只审查按约定范围完成取证后交付。获授权的修订须复验，约定关键行为符合已确认预期且证据齐备时才报告行为验证通过；受阻时交付实际进度与缺口。其他阶段发现带证据、影响及接续条件交 Main，按[阶段授权与推进](../../sdd/references/sdd-repository-governance.md#阶段授权与推进)处理。
