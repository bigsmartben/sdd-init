# SDD 强制架构基线：运维与可观测

> 本仓库现行强制基线；项目蓝图引用并映射稳定 ARC，专题细化契约。规则适用不代表实现或验收通过。

## 职责与隔离（SDD-OBS-01）

可观测由日志和指标组成：日志记录事件、结果及关联事实，指标表达运行状态和统计量。评测消费日志、指标及明确授权的测试资产并形成报告，不作为第三类观测采集；业务或测试资产由所属能力管理。
业务领域负责业务执行及权威业务状态，提供必要事实和明确接入点；日志格式化、存储、轮转、采集导出、统计和展示由运维与可观测领域承担。业务可通过统一接口报告事实；不要求指定日志库、事件总线或独立进程。
观测不得持有业务状态、改变业务语义或直接驱动业务决策；业务不得依赖观测计算或评测结果推进。职责隔离始终适用；文字事实常态记录，媒体保存遵循下述边界。

运维与可观测不得阻塞业务执行，不得对业务产生副作用。业务推进不得等待日志或指标写入、观测导出或评测完成；观测异常、超时、不可用及缓冲饱和不得传播为业务失败、反压业务链路或改变业务执行结果。不得修改业务输入/输出及状态，不得消费或关闭业务仍需使用的流和资源，不得因观测重试而重放业务操作。必要事实采集须采用不阻塞业务的接入方式，并隔离观测任务的资源与生命周期；具体机制由项目选择，不以异步调用本身作为已满足隔离的证据。
持久化要求与业务非阻塞要求同时成立。观测故障通过独立状态、错误及缺失证据显式暴露，按项目策略缓冲和恢复，不靠暂停、取消或拒绝业务来保证日志完整；无法完整保存时如实判定记录要求未满足，不能静默丢弃、伪装保存成功或宣称无限故障下仍保证无损。

## 日志、指标与媒体保存边界（SDD-OBS-02）

必要文字输入输出、执行及工具事实、状态和用量常态记录并持久化，以唯一权威事实（SSOT）供查询、观测和评测派生读取。Debug 只是日志级别，可按级别筛选；它不是独立观测功能、采集开关或媒体保存授权，不因级别设置停记、拒写或清空必要文字事实。流式、取消和中断保留实际部分内容、身份、顺序及缺失事实；生成、发送与呈现分开，缺失不补造，凭证和 API Key 排除在日志之外。

观测日志、指标、队列和归档不得保存原始音视频字节，包括 PCM、编码数据、base64 及其他等价表示；可以记录合法元数据、状态、统计和资产标识，不复制音视频内容。声纹测试、唤醒词等明确业务或测试目的需要的原始音频，由相应业务／测试能力独立管理资产；该例外不使资产成为观测日志，也不授权常规会话录音。原始视频没有已授权保存例外；未明确的其他例外不得推定。正常业务瞬时处理、传输和播放不属于本保存禁令。

<a id="有限资源下的项目策略"></a>

文字记录以精确持久化回执确认，不以控制台、内存、队列或发送代替；失败、缺失或未知应可识别且不阻塞业务。项目在所属正文明确缓冲、容量、保留、饱和与恢复策略；观测重试不得重放业务。业务继续和记录完整分别取证，不承诺无限故障下无损。

## 跨语言日志契约（SDD-OBS-03）

各语言、客户端与服务端文字日志遵循项目唯一、版本化的日志契约：输出格式与编码、字段类型、时间与单位、级别/事件语义、来源/程序版本、会话/请求/调用关联、阶段/顺序、文字内容或合法资产标识、结果/错误、完整性和未知值语义。不得各语言各定一套。
项目必须明确机器可解析的统一输出格式；实现库与存储介质可因宿主而异，不能降低内容及持久化要求。禁止用成功代替未知、用生成完成证明实际呈现，或以媒体引用存在证明文件已经落地。

## 映射、审查与闭环

- 新项目蓝图引用本文件，按稳定项目 ARC 映射以上三项；需求细化行为验收，专题/工程规范细化实现契约。基线 ID 用于跨项目追踪，不替代项目 ARC 编号。
- 已有项目升级保留现行正文，核对基线到 ARC、需求和规范的映射。漏项或冲突形成明确差异，由 Agent 在文档授权范围内选择 sdd-doc 原位归并；不能因未映射而把基线当作可选，也不由初始化器改写已确认正文。
- Review 必查文字常态持久化与 SSOT、日志级别不影响必要文字记录、观测各写入及重试入口拒绝原始音视频字节，以及明确业务／测试音频资产与观测隔离；按 O3 分别提供业务故障隔离、媒体拒收和资产归属证据。指标仅使用合法元数据和统计，不复制媒体。
- 逐项记录基线 ID → ARC/条款 → 检查对象 → 证据/快照 → 结论。证据不足为 UNVERIFIED，契约冲突为 BLOCKED，已证实违反为 FAIL；实现未整改或检查缺口不得给 Review Gate PASS。不得以 Debug 关闭证明媒体拒收，也不得将资产存在当作观测保存授权。
- 发现偏差 → 在授权范围整改 → 复核受影响项 → 更新同一最新快照证据。要求独立审查时由原独立审查者复核。实施或 Test 的接续由 Agent 按任务契约与已有授权选择；完整真实交互/系统验收由 Test 流程承担，局部自验不冒充完整验收。
- 安装成功、文档引用及机械校验均不证明语义满足。通用工具不凭关键词自动判定架构通过。
