# HTML 原型交付

原型是文档交付物。只表达已讨论的界面结构、关键交互与业务状态，不用模板补造业务决定。模拟数据与结果须可辨识，不接入产品业务写接口。

源码由目标项目版本管理，使用隔离的 HTML/CSS/JS，不修改产品源码、组件、接口或运行配置。目录、托管平台和访问方式按实际项目确定，本资源不设置默认平台或发布脚本；未确定时说明影响并只继续不依赖该决定的内容。

制作候选后检查关键操作和模拟状态，确认预览入口对应源码版本并可访问，给出操作说明让用户反馈。需访问权限时提供取得方式，不把凭证写到 Issue。未能验证用户访问时如实标为待核验。

Issue 使用[引用模板](../assets/prototype-reference.md)记录入口、源码及固定版本、适用范围和确认情况。已确认版本保留可追溯入口，新候选使用新版本，不静默覆盖；只有 latest 或临时地址不能表示确认版本。预览失效时报告并恢复对应版本访问，不能换成不同内容沿用旧确认。

用户操作并确认后才记录已确认。需求文字与原型冲突回到讨论；结构、交互或业务状态变化重新确认。正式产品沿用项目组件库或设计规范，原型确认不代表真实系统验收，纯样式和像素还原不作为符合性检查。
