# 文档写入规则

sdd-doc 沿用已确认的意图，依据已确认结论或真实执行证据核对目标正文及关联影响，完成写入和一致性检查。

1. **取证**：读取目标正文、同义条款、上下位约定与直接引用，以已确认结论或用户指定来源为依据。沿用 Skill 已定位的权威实体。内容层级难以判断时查[场景提示](scenarios.md)，按问题核对需求与架构各自的权威依据。
2. **归并**：沿用已有记录，不自动迁移历史。原位保留唯一正文，其他位置引用，删除已替代、失效或重复表述，不追加变更说明。保留稳定编号、追溯关系及不同对象、前提、条件、例外、禁止项和验收含义；下位不得改变上位要求。
3. **同步与核对**：更新受影响条款；入口新增、移动或替代时同步索引与直接引用。读回文件并对照来源、diff 和下表核对完整性、归属及可执行前提，迁移同样逐项核对承接。检查术语、结构、编号、表格、链接、锚点、编码；模板链接按产物实际目录重定位。
4. **机械检查**：按[文档 CLI 用法](doc-check.md#使用)对修改及直接受影响的 Markdown 执行校验，不默认全仓扫描；失败后修复并复查，无关存量问题不扩大范围。CLI 不替代语义、条件例外或证据充分性的判断。
5. **处理缺口**：来源不清、未确认或冲突的内容不固化为决定；新设计取舍、不可执行的上位要求及无法消歧的问题，集中报告位置、影响与待决项，交回讨论，不自行补方案或删要求。

完成时报告落点、关键归并、检查命令与范围、诊断、语义结论及未检查／未解决项。设计文档写入时发现关联 Code Review Rules 可能过时，在回复中简短提醒，由用户决定何时更新；不新增全量检查、自动维护规则或审批。

## 按对象读取与语义核对

按对象与语义影响选用下表，已有结构内的修改同样适用；不加载无关资源或机械填满模板。模板只规定结构、字段及填写约束，不授予设计或执行权限。

| 对象 | 读取依据与结构参考 | 写后判断点 |
|---|---|---|
| 具体需求 | 项目索引、权威实体、[需求模板](../assets/spec_template.md) | 承接适用高位用例与验收维度；详细行为、条件、异常及 AC 完整；不复制蓝图同层级正文，不把实现缺陷写成需求变化 |
| Blueprint | [蓝图模板及架构表达判定](../assets/blueprint_template.md#架构表达与判定) | 保持产品高位抽象，细节引用 Spec；准确承接已确认职责、权威状态、权限、依赖、运行与失败边界、取舍；不加载架构规范，不补入其条款或映射，架构符合性归 Review |
| 接口契约 | 架构表达判定、适用 Blueprint／ARC、[契约模板](../assets/contract_template.md) | I/O、调用双方、状态与副作用归属、受理／完成及异常语义承接确认内容 |
| 场景时序 | 架构表达判定、需求与契约、[时序模板](../assets/sequence_template.md) | 参与者、请求／回执、先后／并发、取消／迟到、未知／恢复承接契约；箭头不暗示未确认成功或同步等待；结果和进度引用报告及 Status／任务 |
| 原型引用与确认 | [原型规则](prototype.md)、[引用模板](../assets/prototype_reference_template.md) | 核对入口、固定版本、模拟边界及确认来源；沿用规则规定的版本保留、冲突及重新确认条件，原型代码归 coder |
| 测试报告 | [报告模板](../assets/test_report_template.md)、test 与 imp 返回证据。需核对验收边界时读[测试范围约束](sdd-repository-governance.md#测试范围约束) | 按报告模板核对必备内容、统计与明细、未执行项及批次归属；核对问题引用，Gate 与人工确认取自对应执行者或用户反馈 |
| Issue | [Issue 模板](../assets/issue_template.md)、发现报告、imp 返回及验收执行者结论 | 按 Issue 模板核对稳定身份、处理历史及报告／Task 引用；修复状态取自 imp，关闭取自验收执行者，人工确认取自用户反馈；不自动创建平台议题 |
| 架构 Review 记录 | [Review 模板](../assets/review_template.md)、sdd-review-code 与 imp 返回证据 | 在各检查项下落盘依据、初审、Task 引用、状态和复核；保留初审和版本，修复状态取自 imp，方案仅引用其 Task，关闭与 Gate 取自复核执行者；不另建独立差异清单或重复维护通用报告 |
| 实施 Plan | [Plan 模板](../assets/plan_template.md)、sdd-imp 清单及证据 | 保留同一计划、依赖、完成条件、状态与证据；不重新拆分方案或用格式检查判定完成 |
| Quickstart | 测试范围约束、[指南模板](../assets/quickstart_template.md) | 承接已确认范围、场景／AC、适用原型及契约，以及执行者据此准备的数据与操作依据；核对准备内容未改变验收含义、范围或标准，操作与观察点足以判断多步骤过程；不补定范围和标准，不复制结果 |
| Status／当前任务 | 测试报告、执行者状态；新建时用[状态模板](../assets/status_template.md) | 报告引用、版本、覆盖及状态对应；只引用逐项结果、Gate 和人工反馈 |
| README 与索引 | 项目权威正文、工程资产规则 | 只定位导航，已有正文不继续指向模板；同步直接受影响入口 |
