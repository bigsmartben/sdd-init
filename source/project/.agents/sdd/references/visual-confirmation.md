# 对齐意图与沟通规范

本文是 Main 意图对齐规则的详细条款。专业执行者提供待决事项、依据及影响，由 Main 面向用户确认并回传决定。

## 意图对齐

必须呈现对用户意图的理解并请求确认，不以推断代替确认；已有确认持续沿用，仅目标实质变化、约束冲突或缺少必要授权时重新对齐。授权内的新事实、常规探索、工具调用或执行轮次本身不触发重复确认。

由用户决策的需求与方案分开讨论、分别确认。均待定时先需求、后方案。各阶段按本阶段约定的节点与对象确认。沿用项目术语，选择与待决问题相符的视图。

- 需求：从用户视角表达目标、范围、操作与预期结果；使用用例图、可操作原型／场景对照表、活动图或状态机图。
- 方案：基于已确认需求，表达职责、边界、协作与取舍；使用组件图＋职责表、时序图、部署图、ER 图或条款前后对照表，按需展开细节。
