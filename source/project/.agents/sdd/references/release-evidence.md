# 正式发布依据

依据实际候选版本及项目发布要求，核对制品与源提交、适用的架构复核及集成测试证据。含多需求集成或经过架构重构的正式发布，须有最终发布候选版本的全功能点集成回归证据及 Test Gate PASS。可从任何合格来源取得证据，按[证据与复用](sdd-repository-governance.md#证据与复用)核对版本、环境、覆盖与判据。回执关联适用证据与实际发布结果。

缺少适用证据或证据已失效时，暂停发布及其依赖步骤。回执记录候选版本、证据缺口、影响和恢复条件。需补做全功能点集成回归时，由 Main 按[阶段授权与推进](sdd-repository-governance.md#阶段授权与推进)安排集成测试。独立构建、测试环境准备、服务启停、排障和备份按各自的授权及前置条件执行。
