# 发布、环境与服务运行

按[交付与运行规则](delivery.md)确定的终点执行。部署、启动或重启沿用已确认的目标环境，适用共享默认约定时使用 dev。核对实际环境和版本，无法消歧时在回执中记录目标缺口。部署类动作及其自动入口在变更或触发前按[执行前确认与部署评估](delivery.md#执行前确认与部署评估)向实际调用者回报评估，沿[交付与运维交接](delegation.md#交付与运维交接)核对回传的告知及适用确认。

## 制品与版本发布

1. 定位源 SHA、发布对象、版本、目标仓库或渠道、审批要求与连带效果。沿用项目的构建入口、流水线、发版工具和制品仓库。正式发布须满足[正式发布依据](release-evidence.md)。
2. 回读已有标签、发行对象及制品。版本与内容一致时复用。发现同名版本已指向不同内容时保留原状态并返回冲突。部署已有制品时核对实际获取的不可变标识及源 SHA，避免可变标签或分支在并发操作中换指。
3. 基于已核验的源提交构建，或使用已核验的制品晋级。关联实际运行或构建编号、源 SHA、制品版本和摘要或等效不可变标识，回读制品在目标仓库或渠道的发布状态。制品发布任务到可核验的发布回执结束。涉及运行版本的发布继续检查环境就绪和约定冒烟。

## 环境与服务运行

1. **探测与定位**：读取项目 AGENTS、运行指南及环境配置，遵循[环境架构规范](architecture-rules.md#环境架构规范)。落地前检测本地操作系统、可用工具与运行时、连接上下文、既有服务、端口和依赖。远程部署另核对目标环境，确定部署入口、版本和就绪判据。
2. **准备环境**：沿用项目明确的部署规范。dev 缺少约定且适合容器化时优先 Docker Compose，复用已有 Compose 配置与项目标识。其他环境按实际条件选择。授权内准备和修复工具、依赖、网络与存储。按实际宿主和运行时解析路径并验证挂载。共享依赖兼容才复用，隔离项目数据与凭据，保留持久化数据和其他项目资源。凭据使用环境既有管理方式，文档和日志只记录非机密信息。新增运维资产或改变其用途时查[工程资产边界](sdd-repository-governance.md#工程资产边界)。
3. **部署与运行**：按下表执行，复用服务标识、部署位置和端口，遵循既定副本与更新策略。冲突先查归属，不通过新开实例、随机端口或另一套环境绕过；仅处理目标服务，保留其他项目实例。
4. **就绪与恢复**：核对实际运行版本、实例／副本、端口、健康状态、必要依赖及适用的流量配置，由既定服务管理机制持续运行。检查与本轮操作相关的日志，从目标访问入口执行约定的发布冒烟并记录版本、覆盖与结果。失败按[回滚与故障恢复](recovery.md#回滚与故障恢复)处理。就绪回执可作为已明确范围的用户功能集成测试的环境输入。

| 请求与现状 | 执行行为 |
|---|---|
| 搭建环境或调整配置 | 核对环境拓扑、对象、配置来源和依赖，按授权应用差异并核验实际生效，按需要检查服务就绪 |
| 首次部署或更新 | 必要构建与部署；已有服务更新并重启，无实例则启动 |
| 启动已部署服务 | 已停止则启动；目标版本已健康运行则复用 |
| 重启服务 | 通过既有管理入口重启；无实例则按部署配置启动 |
| 停止服务 | 经既有入口停止指定服务，核对停止状态以及受影响的访问和依赖 |
| 重复请求 | 回读版本与状态，继续未完成动作，避免重复创建服务 |
| 排障 | 先定位版本、环境、症状和时间窗，查状态、日志、事件、依赖或指标；仅执行授权范围内的修复及复验 |

## Kubernetes

核对 kubeconfig 的目标 context、集群、操作者和 namespace，显式限定查询和写入目标，并检查权限、资源归属及实际部署入口。确认工作负载、声明式配置来源及管理者。项目由 GitOps、发布控制器或流水线管理时，按其权威来源和协议操作；直接变更仅适用于项目约定且已授权的路径，事先处理声明式来源与在线状态的同步。

写入前核对当前修订、实际镜像或制品及变更差异。写入后按该工作负载的控制器和项目约定核对目标修订、实际镜像版本、就绪副本、服务入口及必要依赖。排障按需检查工作负载条件、Pod 事件与日志。超时、状态不明或发现并发发布时回读并区分本轮与他人修订。参考 [kubeconfig 上下文](https://kubernetes.io/docs/concepts/configuration/organize-cluster-access-kubeconfig/)、[Deployment 状态与更新](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/)。

回执按路径提供发布对象、源 SHA、制品标识与发布状态，或目标环境、实际运行版本、服务及就绪状态、访问与日志入口、冒烟结果、排障证据及剩余阻塞。
