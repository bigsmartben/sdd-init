# 模块契约模板

> 只记录已确认且有效的契约，按[项目资产规则](../../governance/repository.md)维护唯一正文。可作为既有接口契约的模块章节使用，不规定文件位置或内部设计图。

按适用范围说明公开输入输出、前置条件及调用方向、授权和信任边界、身份与来源关联、状态权威、实际结果、取消、迟到和失败语义，以及共享数据生命周期和版本；职责、依赖、状态权威及不变量以目标项目索引所指的蓝图为准。共享协议引用其权威正文，跨模块交互与关键竞争引用目标项目索引所指的总时序。厂商、检索、存储等有效细节归所属模块章；不能为了缩减结构丢失不同前提和边界的有效契约。

内部类图和能力流程图不强制；需要时可使用图表达已确认关系，不以图补造职责或接口。未确认的任务形成、参数准备、控制路径等归属集中列入任务或 Review 结论，不从实现反推。按[可观测基线](../references/observability-baseline.md)核对 SDD-OBS-01/02/03 与目标项目稳定 ARC 的映射；文档核对不等于实现审查或验收。

总时序按[跨模块时序模板](sequence-flows.md)维护。复杂分支、并行汇合或数据加工确有收益时可按需使用活动图，区分控制流与对象流。状态机与 ER 按生命周期或关系复杂度需要使用；内部类图默认不要求。厂商、迁移与检索细节在所属模块章节按需阅读，不作为所有任务前置。
