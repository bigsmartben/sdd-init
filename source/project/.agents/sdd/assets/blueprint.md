# 架构蓝图

默认落点：`docs/blueprint.md`。按项目映射引用场景时序与接口契约。

> 按任务需要裁剪，只记录已确认架构；模板不预选组件库、技术栈或产品模块，不要求为普通工具维护建立蓝图。

## 依据与目标

引用相关 Issue、既有架构与约束，说明必要取舍、代价及适用条件，不复制需求正文。

## 职责、接口与依赖

模块责任、输入输出、允许的依赖与协作关系；沿用实际项目边界。

## 状态与不变量

权威状态归属、读写与副作用职责、关键顺序、异常和恢复边界。沿用已有约束编号，只保存已确认规则。

## 实现映射与待决

按需要指向实际代码或专题；区分目标架构和当前实现。未决决定及其影响如实保留，实施步骤与结果引用 Draft PR。
