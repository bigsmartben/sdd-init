# 项目文档

按任务问题进入本项目实际权威章节；尚未建立正文时，使用下列模板。首次建立入口时以实际章节链接替代相应提示。工程资产与默认落点见[仓库治理](../.agents/governance/repository.md)。

- **用户要完成什么，界面如何操作？** 查能力需求及其原型；初次编写使用[需求规格](../.agents/sdd/assets/issue.md)和[原型引用](../.agents/sdd/assets/prototype-reference.md)。
- **谁决定，什么条件下才能报告成功？** 查[蓝图](../.agents/sdd/assets/blueprint.md)、[场景时序](../.agents/sdd/assets/sequence.md)、[接口契约](../.agents/sdd/assets/contract.md)的适用章节；此处链接为模板。
- **候选方案在什么条件下可行？** 查能力的验证主题与复现入口；初次记录使用[实验记录模板](../.agents/sdd/assets/experiment.md)。
- **验证哪些情形，这一版实际做到了吗？** 查对应要求、测试计划与指定版本报告；初次编写使用[测试计划](../.agents/sdd/assets/test-plan.md)与[验收报告](../.agents/sdd/assets/acceptance.md)模板。模板本身不能证明通过。
