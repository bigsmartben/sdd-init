# SDD 初始化与升级

用户明确发起时，Main 默认启动独立初始化技能 Agent，交接目标、授权、终点和必要资料。初始化技能 Agent 核对目标项目、操作、分发来源和版本，以及本轮是否更新用户级安装、刷新指定项目接入或两者都做。沿用已明确的请求。用户级安装一并更新共享资源及通用提示词审查角色，核对影响范围及实际安装路径。命令见[安装与恢复](assets/install.md)。

1. 运行授权范围内的 `inspect`，检查来源、版本、链接、托管导航、角色配置、载荷完整性、冲突和未完成事务。只检查时返回实际状态、路径及建议，结束本轮。
2. 按恢复记录处理授权内的未完成操作，随后重做受影响的预检。同名自有资源、遮蔽入口、定制托管块或归属不明时，给出具体路径、差异及保留、迁移或替换的影响，由用户裁决。范围扩大或需新增权限时确认相应事项。常规检查、标准迁移、配置写入和授权内恢复直接执行。
3. 按已授权的范围更新用户级安装、为指定项目执行 `init`。两者均获授权时先执行用户级安装，再刷新项目链接、托管导航、项目角色注册和安装元数据。项目首次接入、升级和新工作区重连共用 `init`。保留项目自有正文、历史证据、模型、MCP 和其他配置；已有正文的归并、业务迁移及内容补齐交 Main。
4. 用回执和 `inspect` 核对实际版本、资源可达性、Skill 入口、角色配置、导航、适用迁移及事务状态，确认再次执行无待写项。客户端可查时，刷新项目并核对实际发现和可信项目配置。出现失败先查询实际状态，按记录恢复本次触及的文件和链接。遇到外部编辑或损坏记录时保全数据，返回受影响路径和恢复入口。
5. 向 Main 返回共享版本和影响范围、实际用户角色路径（适用时）、项目新增／更新／保留项、可用入口、核验结果、冲突和恢复条件。安装阶段到此结束。设计、实施、验收、发布及 Git 交付由 Main 按用户的阶段授权协调。

初始化技能 Agent 直接调用安装工具完成阶段闭环。待安装的 Skill 和角色作为载荷核验。复杂环境排障确需协作时，显式安排已可用的执行者，交接目标、授权、文件边界、输入和完成判据，回收环境事实和验证结果。发现安装器或分发源码缺陷时，先完成本次可执行的恢复，附诊断交回 Main 由用户决定源码维护。

项目通过 AGENTS 托管导航定位 Main 职责、阶段授权、执行协作和模板。源码维护时在隔离 Skill 和用户角色目录及临时项目验证接入。
