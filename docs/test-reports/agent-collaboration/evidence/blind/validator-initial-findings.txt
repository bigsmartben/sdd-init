# 初始验收与架构审查证据

执行范围：隔离项目本地 CLI／库，初始实现快照；不访问网络或真实外部服务。版本标识为 `evidence/validator-initial.txt` 中 runtime_details 输出的各 src 文件 SHA-256；本任务禁止 Git，未采集 commit。Python 3.14.6、SQLite 3.50.4，运行配置和完整输出同文件。

## 初始验收

命令 `python -B checks/acceptance.py`，退出 1：AC-1 PASS（true，重开文件数据库为 submitted）；AC-2 FAIL（取消后返回 true，重开为 submitted；期望 false、cancelled），问题 ISS-001；AC-3 BLOCKED，配置无端点、无调用权限，未访问网络。`python -B checks/runtime_details.py` 退出 0，运行事实及源哈希见原始输出。`python -B -m unittest discover -s tests -v` 退出 0、2 项通过，原始输出见 `evidence/validator-baseline-unittest.txt`；其仅覆盖正常提交及 paid 持久化，未覆盖取消后提交或数据库异常，不能替代验收。

ISS-001：`src/order_service.py:28-31` submit 读取状态后无条件调用 `set_status(..., "submitted")` 并返回 true，覆盖 cancelled。整改目标为取消后不写入且返回 false，重开仍 cancelled；保持既有函数接口、pending 提交和持久化、数据库异常向上传播及无网络调用。复现入口同 AC-2 验收；修复后须重走 AC-1、AC-2 和受影响组合。

AC-3 恢复需有权人员提供已授权测试服务端点及调用权限，并明确实际核验入口／协议；现有 `checks/acceptance.py:14-22` 无条件返回 BLOCKED，即使配置就绪也不会调用服务。不能用本地结果冒充外部回执；本轮无外部配置、凭据或调用授权。
