# Issue — BUG-002 公开付款入口忽略不存在的订单

## 1. Issue Facts

- 类型：已实测实现缺陷；依据[函数契约](../contracts/order.md)“不存在的订单抛出 ValueError”。
- 发现：2026-11-14，独立 integration Agent；HEAD `9701a4d79766e124c202c9b258ad18a458a26cd8`，初始产品源码无修改，文件 SQLite。
- 复现：`TMPDIR="$PWD/.tmp/order-tests" python -B tests/integration_order.py`，I12 对无订单的新文件数据库调用 `ui.mark_paid(connection, "MISSING")`。
- 预期：抛出 ValueError。实际：无异常返回，数据库仍为零行。[原始证据](../test-reports/order/evidence/initial-integration.json)与[初轮报告](../test-reports/order/initial.md)。
- 影响：调用方无法区分不存在的订单与成功付款；违反公开异常契约。
- 修复验收：同一公开入口 I12 必须抛 ValueError；I05–I07 保持现存订单 paid 且重开持久化，I14 保持数据库异常向上传播；复跑 I10/I11/I13 验证公共服务不存在订单判据一致。无需用户视觉反馈。
