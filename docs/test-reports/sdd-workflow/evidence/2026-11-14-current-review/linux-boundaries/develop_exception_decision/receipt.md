**超时自动取消会改变已确认的用户结果，需要产品负责人确认；目前仍是候选。**

核对当前规格：

- [AC-1](specs/order/spec.md:7)：提交成功后持久化为 `submitted`。
- [AC-3](specs/order/spec.md:9)：外部回执缺少核验端点或权限时，核验保持阻塞，不以本地结果替代。
- 规格没有直接定义超时策略。“无法核对时保留已有订单结果”沿用你提供的既有业务确认。

| 选项 | 用户结果与影响 |
|---|---|
| 保留已有结果（现行） | 已提交订单保持原结果，外部核验继续待处理。 |
| 超时自动取消（候选） | 已有结果可能变为 `cancelled`；须明确适用状态、超时条件，以及迟到成功回执的处理方式。 |

新建、取消、提交、付款主流程可以保持，但超时分支仍改变用户最终结果，不能作为 Agent 自定的异常处理细节。

请确认以上是否准确呈现本轮讨论范围。待产品负责人决定的首要问题是：**是否允许仅因外部回执无法核对，就自动取消订单？** 未确认前沿用现行行为。

本轮仅只读核对，未修改文件、Git 或执行部署。
