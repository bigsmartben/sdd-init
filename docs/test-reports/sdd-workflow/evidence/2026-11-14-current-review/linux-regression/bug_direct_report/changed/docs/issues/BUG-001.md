# BUG-001 — 空输入解析返回空列表

## 1. 问题事实与归因

- 类型：已证实的实现缺陷。
- 依据：[用户工单](../../TASK.txt) 确认空输入应返回空列表，保留非空字符串按逗号拆分。
- 环境：当前隔离项目，Python 3.12.3；初始工作区干净，HEAD `2d9fd8ecd137d6c5c4a0d1092aa33dec6fa5096c`。
- 复现（2026-11-14，Bugfix Agent）：`python -B -c "from src.parser import parse; print(repr(parse(''))); print(repr(parse('a,b')))"` 输出 `None` 和 `['a', 'b']`，退出码 0。
- 已验证原因：[parse](../../src/parser.py) 在空值分支显式返回 `None`；空字符串必经该分支；非空字符串经 `split(',')` 返回列表。直接路径与运行结果一致。
- 影响及边界：只恢复空输入返回列表的契约，不引入额外解析规则，不变更非空字符串逗号拆分行为。
- 授权终点：本地归因、修复、定向复验及工单闭环；不得提交、推送、访问外部平台或部署。

## 2. 验收计划与方案

实施者完成局部自验后，由 Bugfix Agent 在实际修复工作区独立复验。通过真实公开入口 `src.parser.parse` 调用，使用以下数据与断言；无需外部依赖或人工反馈。

| 场景 | 操作 | 通过判据 |
| --- | --- | --- |
| 原故障 | `parse('')` | 等于 `[]` 且类型为 `list` |
| 非空逗号拆分 | `parse('a,b')` | 等于 `['a', 'b']` |
| 无分隔符 | `parse('item')` | 等于 `['item']` |
| 拆分边界保持 | `parse(',a,,')` | 等于 `['', 'a', '', '']` |
