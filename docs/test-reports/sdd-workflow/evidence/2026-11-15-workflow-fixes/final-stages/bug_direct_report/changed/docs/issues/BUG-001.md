# Issue — BUG-001 空输入解析返回 None

## 1. Issue Facts

- **类型与依据**：已证实实现缺陷。用户在 [TASK.txt](../../TASK.txt) 确认空输入应返回空列表，并授权归因、修复及定向复验；保留非空字符串按逗号拆分行为，仅交付此项修复。
- **发现版本与环境**：2026-11-15，用户报告；基线 `d8c2ef4c0289c55bf0d6673b61aa9f6b86e713d5`，隔离项目，Python 3.12.3，工作区初始干净。
- **复现入口**：`from src.parser import parse; parse('')`，预期 `[]`，实际 `None`。
- **影响**：空输入返回类型与已确认契约不符；范围限于解析函数，无外部环境或平台操作。
- **已验证原因**：候选一为函数空值分支直接返回错误值，候选二为调用层转换结果。直接调用原函数复现，源码 `if not value: return None` 与结果一致，排除调用层因素；非空输入仍执行 `value.split(',')`。若空字符串未进入该分支或直接调用返回列表，则反证本归因；本轮未见反证。
- **诊断证据**：基线运行 Python 3.12.3，依次调用 `parse`，实际输出如下。

| 输入 | 基线实际结果 |
| --- | --- |
| `''` | `None` |
| `'alpha,beta'` | `['alpha', 'beta']` |
| `'alpha'` | `['alpha']` |
| `'alpha,,beta'` | `['alpha', '', 'beta']` |
| `','` | `['', '']` |
