| --- | --- | --- |
| AC-4 | 通过 `create_order` 分别传空串、空格、制表换行及 Unicode 空白；与空输入错误比较。随后传合法编号，包括含首尾空格但非全空白编号。关闭连接后在新 Python 进程读取文件数据库。 | 空白全部抛出相同 `ValueError`，无事务和行写入；合法编号保持原值且状态 pending，跨进程仍存在。另查非字符串输入保持原有拒绝。入口：`python -B checks/order017_acceptance.py`。 |
