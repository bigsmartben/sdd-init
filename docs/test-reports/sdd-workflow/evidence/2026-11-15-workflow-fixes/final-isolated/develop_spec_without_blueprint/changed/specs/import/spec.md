# 导入规格

## 1. 依据与范围

- 已确认依据：[WO-IMPORT-010](../../docs/import-work-order.md#wo-import-010)。本规格沿用该工单已确认的范围、主要行为及验收要求；项目暂无 Blueprint，本次以签发工单作为需求依据。
- 适用环境：本地 CLI，通过标准输入提交逐行记录；调用方观察标准输出中的成功、失败计数及退出码。
- 本轮仅归并规格与检查引用，不包含实现、运行验收或部署。

## 2. 当前需求

- FR-001：CLI 从标准输入处理逐行记录。
- FR-002：导入时忽略空白行；空白行既不计为成功，也不计为失败。
- FR-003：任何非空白行继续按既有解析处理，其解析结果、成功与失败计数及退出码语义保持不变。仅增删空白行不应改变非空白记录的处理结果。

## 3. 验收标准

下表定义后续实现的通过判据，不代表已执行验收。以既有 CLI 行为确定有效行及解析失败行的对照输入；比较时保持非空白行的内容与顺序不变。记录输入、CLI 入口与实际版本、标准输出计数及退出码作为证据。

| ID | 前置条件 | 操作 | 通过判据 | 对应需求 |
|---|---|---|---|---|
| AC-001 | 准备仅含空白行的输入，覆盖空行及仅含空格、制表符的行；另准备空输入作为退出码对照 | 分别通过标准输入调用本地 CLI | 仅空白输入的成功计数与失败计数均为 0；退出码与空输入一致，空白行不产生记录处理结果 | FR-001、FR-002 |
| AC-002 | 准备仅含有效非空白行的输入，并取得其既有处理结果作为对照 | 通过标准输入调用本地 CLI | 有效行仍按既有解析处理；标准输出中的成功、失败计数及退出码与对照一致 | FR-001、FR-003 |
| AC-003 | 在 AC-002 的有效行输入前后及行间加入空白行，保持有效行内容与顺序 | 分别导入混合输入及原有效行输入 | 两次非空白记录处理结果一致，成功、失败计数及退出码一致；新增空白行不计入任一计数 | FR-002、FR-003 |
| AC-004 | 准备含既有解析失败行的非空白输入，并取得其既有处理结果；另复制一份并加入空白行 | 分别导入原输入及加入空白行的输入 | 非空白行保持既有解析与失败处理；两次标准输出计数及退出码与既有结果一致，空白行不掩盖或增加非空白行失败 | FR-002、FR-003 |
