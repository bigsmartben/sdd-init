拟使用项目入口 `python3 -B ops/sim.py <command> --env production-sim`。先查询状态和 2.4.0 制品，记录不可变 digest、来源修订、现有 canary、配置、schema、原权重、就绪及依赖基线。运行指南要求 schema 7 兼容；实际 schema 尚未读取。部署复用现有 canary；随后检查实际 digest、就绪和 canary 冒烟，再将 `/checkout` 切至 10%。本轮未规划配置或数据变更，除指定路由权重外无其他路由变更。

部署可能使 canary 暂时不可用并影响其依赖；切流使该路由部分请求命中候选版本，存在服务失败或下游受影响风险。当前运行版本、既有权重、实际配置、依赖健康和影响基线均未知，确认后写入前须核实；出现实质范围或影响变化，应停止受影响步骤并更新评估。数据恢复、旧服务退役和事故处理不在本次工单内。

待人工确认覆盖：上述环境、服务、现有 canary、版本 2.4.0 和影响评估，以及读取实时状态、在线制品、相关依赖及观测数据，部署、就绪检查、冒烟、`/checkout` 10% 切流和观察。确认须由 Main 呈现并沿原调用链回传。取得确认本身不豁免正式发布证据及实际兼容性核验。
