# 导入规格

## 1. 依据与范围

- **已确认依据**：[WO-IMPORT-010](../../docs/import-work-order.md)。工单已由产品负责人确认范围、主要行为与验收观察点，本轮沿用该确认。
- **适用环境与入口**：本地 CLI，从标准输入提供逐行记录，观察标准输出中的成功／失败计数及退出码。
- **范围**：补齐空白行忽略规则及其验收条件，保持非空白行的既有解析行为。
- **本轮终点**：仅维护规格，不实施、不补 Blueprint，不将下述验收条件记为已实测结果。

## 2. 当前需求

- FR-001：CLI 从标准输入处理逐行记录。
- FR-002：导入时忽略空白行，空白行不计入成功数或失败数。
- FR-003：任何非空白行继续按既有解析处理；加入或移除空白行不改变其解析结果、成功／失败计数和退出码行为。

## 3. 详细验收条件

以下条件以标准输入调用 CLI；成功／失败计数的输出格式和退出码的具体值沿用既有行为。比较输入时保持非空白行内容与顺序一致，不新增空白字符分类或解析规则。

| ID | 前置条件 | 操作 | 观察与通过判据 | 需求／依据 | 证据类型 |
|---|---|---|---|---|---|
| AC-001 | 准备仅含空白行的输入，并取得空标准输入时的既有计数与退出码作为基线 | 分别通过标准输入运行 CLI | 空白行不增加成功数或失败数；标准输出中的计数与退出码均与空标准输入基线一致 | FR-001、FR-002；WO-IMPORT-010 | CLI 输入、标准输出及退出码对照 |
| AC-002 | 准备仅含有效非空白行的输入，并取得该输入按既有解析处理时的计数与退出码作为基线 | 通过标准输入运行 CLI | 有效行按既有解析处理，标准输出中的成功／失败计数与退出码保持基线行为 | FR-001、FR-003；WO-IMPORT-010 | CLI 输入、既有行为基线、标准输出及退出码对照 |
| AC-003 | 使用 AC-002 的有效行，在输入开头、行间和末尾加入空白行 | 通过标准输入运行混合输入，并与仅有效行的输入比较 | 空白行不计成功或失败；相同有效行的解析结果、标准输出中的计数及退出码均保持一致 | FR-002、FR-003；WO-IMPORT-010 | 两组 CLI 输入、标准输出及退出码对照 |
| AC-004 | 准备按既有解析会失败的非空白行，并取得该输入的既有失败处理、计数与退出码作为基线 | 分别运行原输入及加入空白行后的输入 | 非空白行继续按既有解析失败处理；空白行不计成功或失败，失败处理、标准输出中的计数及退出码均保持基线行为 | FR-002、FR-003；WO-IMPORT-010 | CLI 输入、既有行为基线、标准输出及退出码对照 |

以上为待实施后执行的点对点验收条件。既有解析行为作为保持项，不在本规格中重新定义；实际运行版本、结果及证据应在获授权执行验收后记录。
