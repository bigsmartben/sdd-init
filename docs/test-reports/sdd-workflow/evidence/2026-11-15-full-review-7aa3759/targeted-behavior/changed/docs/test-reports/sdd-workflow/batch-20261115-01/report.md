# SDD 工作流合成矩阵评审：20261115-01

## 范围与版本

用户本轮显式调用 `$sdd-workflow-review`，按 [合成判据](../../../review-criteria.md) 执行。授权仅限当前隔离项目只读审查、必要本地入口运行和本目录报告；终点为交付报告，未授权修复。未访问已安装工作流、其他项目或真实外部平台。

适用对象为主任务、本地助手、远端助手；逐对象覆盖 4 个矩阵单元格，涉及 RW-06.1、RW-07.1。通用判据的其余子项均不在本次合成矩阵范围，不推定真实 SDD 工作流通过。远端只涉及失败场景，不评审成功行为。

版本采用 [执行前快照](snapshot-before.json)：SHA-256 和字节数固定全部 19 份既有文件，含入口、共享规则、代码、输入产物、配置、Spec、白皮书、Skill、判据、模板及原 README。该夹具没有 .git，无法报告提交号或区分已跟踪/未跟踪状态，以全文件快照代替；没有发现可适用的 AGENTS.md。Skill 引用的 tests/fixtures/skill-behavior/README.md 缺失，本次使用显式合成矩阵及既有本地入口，不引入外部夹具。

直接设计依据为 [夹具白皮书](../../../sdd-workflow-whitepaper.md):3 及 [Spec](../../../../specs/platform-independent-sdd/spec.md):3–4（FR-001、AC-001）；不套用真实项目的 S1～S8 或 FR-008 等不存在于夹具的条款。Skill 通用规则、质量成本口径、报告模板的版本均绑定上述快照。逐行原文见 [静态证据](static-evidence.txt)。

主 Agent 负责 Main、共享规则、引用关系、跨对象归并、取证选择和报告；两个子 Agent 并行分别完成本地、远端静态工单，结果摘要见 [agent-results.json](agent-results.json)。派单配置均为 gpt-6.1-sol / high（由本 Skill 推荐配置）；子 Agent 内部没有独立型号/推理遥测，故仅作为调度配置记录。主 Agent 型号与推理配置未测，运行时不提供对应可核验字段。

本地运行环境：Linux / Python 3.12.3，细节见快照；当前项目为工作目录，Python -B 禁止字节码产物，UTF-8 读取原始文件。受测入口是 Python 程序，无受测模型或 Agent 推理配置。普通工单不含完成标记，原始产物内容为 receipt_id=LOCAL-17。它是用例输入，不是历史执行证据。本轮没有可复用行为报告、比较目标或可比基线，因此不做 A/B。

## 综合结论

**存在 1 项共享规则偏差；本地回读入口实跑通过；远端失败行为证据不足。** 主任务静态要求与设计一致。两个助手都优先采用“凭请求方完成标记直接完成”的共享规则，允许绕过实际回读，故 RW-06.1 不符合。共享事实归并为 F-01，不重复计数。本地普通工单运行证明当前环境能够通过真实入口读取中文和空格路径，不能消除标记分支的规则偏差，也不证明完整模型行为。远端无服务响应，不能据静态文字宣称失败闭环通过。

静态诊断先于实跑，原阶段记录保存在 [static-stage.md](static-stage.md)。随后仅执行 T-01；T-02 保留未执行，未构造远端错误回执。无修复、无修复后复验，报告为本轮授权终点。
