# Plan — 4+1 角色独立性整改

## 目标与依据

按 [Spec](../../specs/platform-independent-sdd/spec.md) FR-011、FR-027、FR-030 及对应 AC 整改角色依赖、注册和交接。以安装器产物和五个隔离实跑回执验证。

## Task 清单

| Task | 改动范围与完成条件 | 依赖 | 状态与证据 |
|---|---|---|---|
| T001 | 同步共享规则、角色、入口与 Spec。角色直接读取任务依据，并向任务调用者交付结果和跨职责事项的证据。 | 无 | 完成。对照[执行协作](../../source/project/.agents/sdd/references/delegation.md)与五份角色源码核对。 |
| T002 | 统一五个角色的分发和注册，验证新装、升级、冲突保护及源码维护边界。 | T001 | 完成。构建后初始化器 22 项、仓库回归 67 项通过。客户端在隔离项目解析到五个角色及对应配置。 |
| T003 | 以最终候选清单逐例实跑五个角色。核对角色浏览器调用与同一 HTML 的回执，核对订单工单的读取、修复前失败与修复后回归，并复验其余三个场景。 | T001、T002 | 完成。五例实际加载角色并交付本职结果，源码、清单和分发载荷哈希一致。见[最终候选复验](../workflow-evidence.md#2026-11-14-41-角色最终候选复验)。 |
| T004 | 对照 T003 快照核对角色级增量。定向验证架构遵循初审与复核、产品验收规格推导、运维发布和备份恢复，核对角色向任务调用者返回回执。 | T003 | 完成。六例增量实跑及五例回执复验通过，版本与回执见[角色变更定向复验](../workflow-evidence.md#2026-11-14-角色变更定向复验)。 |
| T005 | 沿五个角色的实际文件读取和适用引用检查共享规则、验收与运维模板的回执和调度边界，复验受影响分支。 | T004 | 完成。四个受影响分支通过隔离复验，文档一致性沿用原只读证据。见[共享规则与模板复验](../workflow-evidence.md#2026-11-14-角色共享规则与模板复验)。提交前复验通过实施工单缺项、无适用生产确认和已有适用确认三个分支。 |
