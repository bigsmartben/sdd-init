# 工作流 Review 报告：批次名称

使用时将链接重定向至报告所在目录。主 Agent 原位补全同一批次报告。静态诊断先记录依据、发现和待验清单，后续按实际取证与复验更新对应条目，收尾补齐覆盖和成本。逐对象与逐子项共用证据及发现 ID。判据和统计方法分别见[审查判据](../references/review-criteria.md)与[质量成本口径](../references/evidence-and-cost.md)。
