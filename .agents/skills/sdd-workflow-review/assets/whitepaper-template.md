# 工作流白皮书结构模板

只组织已确认、可独立引用的设计内容。填写时保留稳定条款编号和确认依据；未决问题留在相应讨论或决定记录，不写成既定设计。按实际内容合并章节，模板不预设新的业务决定。

## 设计目标

说明服务对象、预期结果与要解决的问题。问题动机不作为当前实现缺陷结论。

## 适用范围与边界

列出能力范围、排除项、目标项目自行决定的事项，以及与 Spec 的关系。

## 问题清单

描述设计要解决的矛盾及影响，关联后续策略。

## 实现策略

用稳定编号组织已确认策略、职责分工、依赖方向、授权边界与有效例外，提供可独立引用的章节。

## 关键取舍

说明已选方案、理由和保留的边界，引用已有策略或决定来源。

## 相关产物

链接适用 Spec、审查 Skill 和批次报告入口。审查规则、RW 子项、对象矩阵、取证与统计方法归 Skill 参考文件；版本结论、发现、证据和实测成本归对应 Review 报告，不填入设计正文。

本模板由 [sdd-workflow-review](../SKILL.md)提供；使用模板不等于启动评审或获得修改已确认设计的授权。
